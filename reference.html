Resources used

Images and 3D model

  • Earth-orbit photograph: Local image file, sourced from Unsplash. The original photographer and image-page URL were not included with the supplied files.
  • Launch photograph: Local image file, sourced from Unsplash. The original photographer and image-page URL were not included with the supplied files.
  • Mars surface illustration: Original concept artwork created for this project and stored as mars-surface.svg.
  • Capsule interior reference: NASA, Dragon Crew Seat Configuration, Crew-8 Dragon cabin. This is a real Crew Dragon interior used as a reference, not an AURORA design. Local image: capsule-interior.jpg.
  • Explorative Space Craft: Generic 3D model by Mitch Lewis on Sketchfab. View the original model. Licensed under Creative Commons Attribution 4.0. The model file is stored locally as explorative_space_craft.glb; it is illustrative and not a Mars-certified vehicle design.

Software and typography

  • Three.js 0.180.0: JavaScript 3D rendering library, loaded from jsDelivr. Three.js project.
  • GLTFLoader: Three.js loader for the GLB model, included with Three.js. See the GLTFLoader documentation.
  • Roboto: Locally hosted regular and bold font files from Google Fonts, licensed under the SIL Open Font License.

Project materials

  • Mission concept, copy, layout, and navigation: Developed by the student team for this educational project. AURORA and its crew profiles are fictional.
  • Supporting documents: Student Copyright Checklist and Work Log.
  • Site icons: Locally supplied favicon, Apple touch icon, Android icons, and web app manifest.
